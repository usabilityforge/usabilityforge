## 🎯 My Testing Approach

I use **task-based usability testing** modeled on real user workflows. The approach blends usability observation and practical support-style insight:

1. **Set clear goals**: e.g., "Can a new user accomplish X without confusion?"
2. **Observe in action**: I walk through features like your actual users would
3. **Capture friction points**: Where does the workflow feel unclear or broken?
4. **Document everything**: Screenshots, short recordings, exact pain points
5. **Report actionable findings**: Not just "users are confused" but "users are confused *here, specifically, because...*"
6. **Flag bugs**: Any technical issues found during testing
7. **Suggest prioritized improvements**: Quick wins first, then medium/longer-term changes

My 4 years as an application support analyst (banks, colleges, health startup) means I’ve listened to real users and can translate complaints into high-impact UX fixes.
