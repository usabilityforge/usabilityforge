I provide hands-on usability testing for:

- Web apps

- SaaS products

**Find friction before your users do.**

Every test includes:

- Clear, actionable usability findings  
- Reproducible bug reports  
- Screenshots or screen recordings (if needed)  
- A breakdown of confusing flows  
- Suggestions to improve clarity and UX  
- Optional follow-up testing after fixes
