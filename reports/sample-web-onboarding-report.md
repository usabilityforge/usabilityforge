# Sample Report — Full Usability Review: Web App Onboarding

**Project**: Example SaaS Onboarding  
**Test type**: Full Usability Review ($75)  
**Date**: Feb 2025  
**Tester**: UsabilityForge  
**Duration**: ~60 minutes

## Test Goals
- Can new users sign up, complete onboarding, and reach "first value" within 10 minutes?
- Identify confusing copy, hidden steps, and drop-off points in the signup flow.

---

## Executive Summary
Users reached account creation but repeatedly missed the optional profile step, which led to later confusion when features required profile data. Two calls-to-action were visually weak, reducing feature discovery. Prioritized fixes will noticeably improve activation and time-to-first-value.

---

## Key Findings

### 1) HIGH — Optional profile step hides required settings
- Observation: Profile setup appears optional but some features require profile data later.
- Impact: Users expect to finish setup; later prompts to complete profile feel like extra work, causing friction.
- Recommendation: Turn critical profile fields into required steps during onboarding or clearly mark why they matter.

### 2) MEDIUM — Weak CTAs for core feature discovery
- Observation: Primary CTA buttons use muted color and generic text ("Continue").
- Impact: Users did not discover main feature until guided by helper text.
- Recommendation: Use stronger verbs and contrasting color: "Create your first project".

### 3) LOW — Success message lacks next steps
- Observation: After onboarding, the success screen just says "Welcome" with no suggested next tasks.
- Impact: Users are uncertain what to do next.
- Recommendation: Add 2-3 guided next steps (create project, import data, run quick tour).

---

## Prioritized Recommendations
1. Make critical profile fields required or explain their value (high impact)  
2. Update CTAs to be action-specific and visually prominent (medium)  
3. Add guided next-step suggestions on completion (low)
